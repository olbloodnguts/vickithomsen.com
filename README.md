# vickithomsen.com

Memorial site for Vicki Lynne Thomsen (1947–2016), served by GitHub Pages.

Plain HTML and CSS, no build step. Rebuilt in October 2026 from the original Weebly site that was hosted at HostGator, keeping its look and wording.

| File | What it is |
| --- | --- |
| `index.html` | Home page: photo, dates, service details, donations, grief resources |
| `obituary.html` | The obituary |
| `css/style.css` | All styling (colors are set at the top) |
| `images/` | Vicki's photo and the sunset banner (metadata stripped) |
| `photogallery/` | Keeps the old `/photogallery` address working (Google Photos album) |
| `familyforum/` | Keeps the old `/familyforum` address working (Google Group) |
| `404.html` | Shown for any address that doesn't exist |

Any push to `main` republishes the site within a minute or two.
